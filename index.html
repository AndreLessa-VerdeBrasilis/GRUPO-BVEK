Usuários e perfis de acesso

Para dar acesso a um funcionário: no Supabase, abra Authentication → Users → Add user → Create new user, informe o e-mail e uma senha provisória e marque Auto Confirm User. Ele aparece aqui como Aguardando liberação: escolha o perfil e clique em Salvar. Depois do primeiro acesso, ele troca a senha no botão 🔑 Senha.
Intermitente (só contracheque): crie o usuário no Supabase com o e-mail CPF@funcionario.bvek.com.br (CPF só com números) e escolha aqui o perfil Funcionário (só contracheque). 💳 Cartões da empresa

O final (4 números) serve para a importação reconhecer de qual cartão é cada compra. O dono é o login que vê e justifica as compras daquele cartão (ex.: Pedro, Bianca).

⬆️ Importar fatura / extrato

No Itaú Empresas, baixe a fatura do cartão (ou o extrato) em OFX, Excel/CSV ou PDF e escolha o arquivo aqui. Pode importar o mesmo arquivo mais de uma vez: o que já entrou é ignorado.

Usado quando a fatura traz só dia/mês.

⚙️ Lembrete no WhatsApp

Enquanto houver pagamento aguardando autorização, o próprio sistema manda a lista para o WhatsApp do André no intervalo escolhido, até que tudo seja marcado como autorizado. Os dados abaixo ficam guardados só no banco de dados (só o Administrador vê).

Como ativar o CallMeBot (uma vez só, pelo celular do André):
1. Abra callmebot.com → WhatsApp e salve nos contatos o número que aparece lá.
2. Mande para esse contato, pelo WhatsApp, a frase: I allow callmebot to send me messages
3. Ele responde com a sua apikey (um número). Cole abaixo, salve e clique em Enviar teste.
Exige conta no Meta Business, um número exclusivo para a API e um modelo de mensagem aprovado com uma variável ({{1}}), onde entra a lista de pagamentos. Sem modelo, a Meta só entrega se o André tiver mandado mensagem para esse número nas últimas 24h.
